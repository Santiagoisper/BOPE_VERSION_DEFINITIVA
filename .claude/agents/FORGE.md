## STACK PRINCIPAL

- **Runtime:** Node.js + TypeScript
- **Framework:** Next.js API Routes / tRPC
- **Base de datos:** Neon PostgreSQL serverless
- **ORM:** Drizzle ORM
- **Auth:** NextAuth.js / Clerk
- **Deploy:** Vercel
- **Validación:** Zod
