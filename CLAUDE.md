# CLAUDE.md

Este repositorio usa Claude Code con bootstrap real en `.claude/CLAUDE.md`.

## Punto de entrada correcto

- Claude Code carga `.claude/CLAUDE.md` automaticamente al abrir esta carpeta.
- Los agentes operativos viven en `.claude/agents/`.
- El estado y los logs del sistema viven en `logs/`.

## Activacion

1. Abrir Claude Code en la raiz del repo.
2. Verificar que exista `.claude/CLAUDE.md`.
3. Escribir `BOPE` en el chat para activar el protocolo.
4. Dar la orden a `JOHN`.

## Archivos clave

- `.claude/CLAUDE.md`
- `.claude/BOPE-CONSTITUCION.md`
- `.claude/ORDEN-DE-BATALLA.md`
- `.claude/agents/JOHN.md`
- `logs/MISION-ACTIVA.md`
- `logs/NOTICIAS-BATALLON.log`

## Nota

El archivo `CLAUDE.md` de la raiz no es el bootstrap canonico. Su funcion es evitar confusion y apuntar al setup real que Claude usa en este proyecto.
