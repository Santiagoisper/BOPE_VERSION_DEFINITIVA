# BOPE global — referencia rápida

## Instalación one-time (Santiago)

1. Skill personal: `~/.cursor/skills/bope/SKILL.md` (este paquete).
2. Config global: `~/.bope/config.json` con `bopeHome` apuntando al monorepo.
3. Opcional: **Cursor → Settings → Rules → User Rules** — pegar `user-rule-snippet.md`.

## Uso

En **cualquier carpeta** abierta en Cursor: `/bope`

## CLI hermano (terminal)

```powershell
bope init
bope doctor
bope bootstrap
```

## Límites

- Save & return institucional completo solo en el monorepo BOPE (modo NATIVO).
- `/warroom` requiere deploy o archivo servido actualizado.
