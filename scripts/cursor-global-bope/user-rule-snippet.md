# Pegar en Cursor → Settings → Rules → User Rules (opcional, refuerzo global)

Cuando el usuario escribe `/bope`, `BOPE`, `bope` o `BOPE ONLINE` en cualquier proyecto:

1. Invocar la skill personal `bope` (`~/.cursor/skills/bope/SKILL.md`).
2. No usar el menú genérico de "listar agentes y esperar".
3. JOHN (John Rambo) es el mando operativo; SANTIAGO es el Comandante humano.
4. Leer doctrina desde `bopeHome` en `~/.bope/config.json` o desde el monorepo si el workspace es BOPE VERSION DEFINITIVA.
5. Responder siempre en español.
