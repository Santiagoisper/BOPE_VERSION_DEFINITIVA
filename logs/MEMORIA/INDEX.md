# MEMORIA BOPE — INDICE — CAPA CLAUDE

Cuando SANTIAGO escribe `MEMORIA`, Claude lee en este orden:

## Secuencia de acceso

1. `logs/MEMORIA/INDEX.md` — este archivo — punto de entrada
2. `logs/MEMORIA/ULTIMO-RESUMEN.md` — resumen operativo de la ultima sesion
3. `logs/MEMORIA/MEMORIA-TACTICA.md` — aprendizajes reutilizables de misiones anteriores
4. `logs/DOSSIER-GENERAL.md` — plantel canonico completo
5. `logs/personnel/` — legajos personales individuales
6. `logs/missions/` — historial de misiones de la capa Claude

## Archivos de memoria

| Archivo | Contenido |
|---------|-----------|
| `INDEX.md` | Este indice — punto de entrada al sistema MEMORIA |
| `ULTIMO-RESUMEN.md` | Estado operativo al cierre de la ultima sesion |
| `MEMORIA-TACTICA.md` | Aprendizajes reutilizables consolidados |

## Archivos operativos

| Archivo | Contenido |
|---------|-----------|
| `logs/DOSSIER-GENERAL.md` | Plantel canonico, rangos, funciones, legajos |
| `logs/personnel/` | 11 legajos personales aislados |
| `logs/missions/` | Historial de misiones |
| `logs/MISION-ACTIVA.md` | Estado canonico actual |
| `logs/NOTICIAS-BATALLON.log` | Anuncios y condecoraciones |

## Regla

Si no esta escrito en `logs/`, no existe en Claude.
