# Skill: Intel Phase

**Cuándo:** Inicio de misión o bug oscuro; antes de tocar código masivo.

## Pasos

1. **Contexto:** qué se sabe, qué no, hipótesis vs hechos.
2. **Fuentes:** logs, commits recientes, docs, repro mínimo.
3. **Superficie:** qué archivos/servicios toca; riesgo de blast radius.
4. **Salida:** informe corto a JOHN con recomendación Single / Paralelo / Colaborativo.

## Límite de tiempo

Si intel supera el valor esperado, cortar y pedir acotación de scope.
