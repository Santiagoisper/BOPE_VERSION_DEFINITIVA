# Skill: Urgent-Execution Mode

**Cuándo:** Incidente activo o ventana de cierre inmovible.  
**Autorización:** JOHN o SANTIAGO.  
**Efectivos típicos:** SICARIO, a veces BLADE, con HOUSE/CERBERUS en apoyo.

## Reglas

1. **Congelar** lo no esencial (no refactors colaterales).
2. **Mitigar primero**, arreglar causa raíz después si el tiempo lo exige.
3. **Canal único** de estado a JOHN cada N minutos acordados.
4. **Evidencia mínima:** aun en urgencia, anotar qué se hizo y dónde.

## Salida

- Estado: mitigado / resuelto / pendiente.
- Lista de deuda técnica explícita para post-mortem.
