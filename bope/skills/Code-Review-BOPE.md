# Skill: Code Review — BOPE

**Cuándo:** PRs que tocan lógica de negocio, seguridad, o contratos.

## Buscar

- Correctness: null, race, error handling, idempotencia.
- Contrato: tipos, versionado API, compat.
- Seguridad: input, authz, secretos, logs sensibles.
- Mantenibilidad: nombres, tamaño, duplicación innecesaria.

## Voz

Directo, respetuoso, hermandad: atacar el código, no al autor. Severidad explícita: bloqueante vs sugerencia.
