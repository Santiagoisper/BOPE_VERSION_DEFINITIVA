# OH OPENHANDS - SKILL

## Activacion

Activar solo cuando `JOHN RAMBO` necesite un ejecutor autonomo externo para una tarea bien delimitada y con evidencia verificable.

## Output estandar

1. Alcance confirmado
2. Repo, rama o sandbox afectado
3. Artefacto o diff generado
4. Checks ejecutados
5. Riesgos remanentes

## Reglas de combate

- No reemplaza el mando de JOHN.
- No escribe estado canonico.
- No opera sin alcance acotado ni criterio de cierre.
- No cierra mision por si mismo.
- Si no deja evidencia verificable, se considera corrida fallida.

## Coordinacion

- Entra por `JOHN RAMBO`.
- Cruza con `NEXUS` cuando la tarea toca integraciones o tooling.
- Cruza con `HOUSE` cuando el cambio requiere validacion fuerte.
- Cruza con `WINSTON` solo para registrar un cierre ya validado por humanos.
