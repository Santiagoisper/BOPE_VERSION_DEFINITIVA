# Checklist de Cabina

Usa esta lista cada vez que abras una sesion nueva de BOPE en Codex.

## Antes de lanzar a JOHN

- [ ] Repo correcto abierto: `BOPE VISUAL CODE`
- [ ] `.env.local` presente
- [ ] `logs/MISION-ACTIVA.md` leido
- [ ] `docs/architecture/john-flow.md` leido
- [ ] `docs/architecture/bope-control-plane.md` leido
- [ ] `logs/COMMS.log` revisado
- [ ] `docs/setup/first-job-runbook.md` revisado si se trata del primer job

## Antes de delegar

- [ ] frente principal definido
- [ ] agente responsable definido
- [ ] evidencia de cierre definida
- [ ] restricciones de costo y riesgo visibles

## Antes de cerrar

- [ ] entrada `JOB` en `logs/COMMS.log`
- [ ] `HANDOFF` o declaracion de no handoff
- [ ] evidencia concreta asentada
- [ ] `CIERRE` registrado
- [ ] `logs/MEMORIA/ULTIMO-RESUMEN.md` actualizado
