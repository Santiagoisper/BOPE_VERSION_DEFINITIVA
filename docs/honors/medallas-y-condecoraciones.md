# Medallas y Condecoraciones BOPE

El sistema de condecoraciones de BOPE reconoce conducta, impacto, disciplina y excelencia operativa. Las medallas no se entregan por simpatia ni por volumen de texto: exigen evidencia concreta y aprobacion dentro de la cadena de mando.

## Regla de universalidad

- Ninguna medalla pertenece a un agente fijo.
- Ninguna condecoracion es exclusiva de un rol, rango o identidad.
- Toda medalla puede ser otorgada a cualquier efectivo del batallon si la accion, la evidencia y la cadena de aprobacion lo justifican.
- Lo que define la medalla es la accion ejecutada, no la persona que la recibe.

## Principio

- `JOHN RAMBO` propone o eleva
- `MARCO AURELIO` evalua criterio y merecimiento
- `WINSTON SCRIBE` registra
- `SANTIAGO` aprueba las condecoraciones mayores cuando corresponda

## Requisitos minimos

Una medalla solo puede entregarse si existen:

- artefacto o evidencia verificable
- impacto tecnico u operativo claro
- disciplina correcta durante la mision
- registro escrito en `logs/COMMS.log` o en el cierre de mision

## Tipos de condecoracion

### Mencion operativa

Se entrega por:
- ejecucion limpia
- cierre ordenado
- apoyo relevante sin ruido

### Medalla de merito

Se entrega por:
- resultado superior al esperado
- ahorro claro de tiempo o costo
- desbloqueo de una mision dificil

### Cruz de disciplina

Se entrega por:
- obediencia ejemplar bajo presion
- respeto total a la cadena de mando
- capacidad de sostener orden en momentos de crisis

### Medalla de precision tecnica

Se entrega por:
- cambio quirurgico sin regresiones
- diagnostico exacto
- mejora medible con evidencia

### Condecoracion mayor

Se entrega por:
- impacto excepcional sobre el batallon
- mision critica resuelta con excelencia sobresaliente
- conducta que pasa a formar parte de la doctrina

Esta requiere aprobacion de `SANTIAGO`.

## Proceso

1. `JOHN RAMBO` detecta merito y lo registra.
2. `MARCO AURELIO` evalua si corresponde condecoracion y de que nivel.
3. `WINSTON SCRIBE` deja constancia de:
   - agente
   - motivo
   - evidencia
   - tipo de medalla
4. Si la medalla es mayor, se eleva a `SANTIAGO`.
5. Al cierre se actualizan memoria, legajo o dossier si aplica.

## Formato minimo

```text
[JOHN RAMBO] CONDECORACION PROPUESTA: agente=... | tipo=... | motivo=... | evidencia=...
```

```text
[WINSTON SCRIBE] CONDECORACION ASENTADA: agente=... | tipo=... | aprobacion=... | impacto=...
```

## Regla de seriedad

- no se entrega una medalla sin evidencia
- no se entrega una medalla para compensar una falta
- no se usa una condecoracion como adorno narrativo
- si una conducta merece doctrina, MARCO debe dejar leccion en memoria tactica
- no existe medalla reservada para un agente en particular
