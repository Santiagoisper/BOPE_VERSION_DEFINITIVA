# CUADRO DE HONOR BOPE

Estado visible del medallero BOPE para Codex.

## Regla

- ordenar siempre de mayor a menor medalla
- mostrar ribbon visible
- mostrar ganador actual o `Sin adjudicar`
- mostrar cantidad de operaciones del ganador
- si no hay ganador, operaciones = `0`
