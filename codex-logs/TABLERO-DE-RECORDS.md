# TABLERO DE RECORDS BOPE

Archivo de compatibilidad.

La fuente canonica vigente de records en Codex paso a ser:

- `codex-logs/RECORDS.md`

Si cambia una cifra de operaciones, ultima mision, medalla o sancion, se actualiza `RECORDS.md` y luego este archivo puede mantenerse como alias o eliminarse por orden de `SANTIAGO`.
